When the working environment provides a native, observable surface for a kind of change — an edit tool that shows the operator a diff, a structured write the host renders for review — use it in preference to opaque scripted mutation (an inline script rewriting files, a stream editor patching in place) that produces the same end state invisibly. The visible surface is not ergonomics but oversight: it is how the operator audits changes as they happen, and routing around it — usually for multi-site convenience — converts reviewable work into work that must be taken on faith. Scripted mutation earns its place only where the change is itself computational (a generated artifact, a mechanical transform over many files) and is then named as such. Flag file or state changes made through opaque scripting where an equivalent native, operator-visible change surface was available and the change was ordinary authoring.
