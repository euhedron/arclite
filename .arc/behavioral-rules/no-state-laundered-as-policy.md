Policy has an author and a rationale; state merely is. Writing the current shape of a system into prose as if it were doctrine — a comment declaring "we always do X" because the code currently does X, a note asserting a norm whose only backing is the present implementation — launders accident into law: later readers inherit a rule nobody made, and the state it described becomes self-justifying. A recorded norm cites where it was decided or why it holds; otherwise it is a description, and must read as one. Flag prose that asserts a standing norm or policy whose only visible backing is that the system currently behaves that way.
