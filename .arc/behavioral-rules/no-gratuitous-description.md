Description is a liability: it drifts from what it describes, demands maintenance, and the next reader — especially an agent — takes it as authority and replicates it. The default amount is none; unjustified prose is deleted, not trimmed. Comments that restate or mirror code — narrating its logic, citing its functions, files, and invocations in prose — are a hand-maintained second copy of the code and the clearest case of the liability. Descriptions of things meant to change, or of machinery meant to be replaced, caption a moving target. Rationale worth keeping is stated once, where it can be cited and revised — never inline, where it hardens into canon. Flag restated or mirrored code, captions on the configurable or the soon-replaced, and decision-rationale narrated inline.
