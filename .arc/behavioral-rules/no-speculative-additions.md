An addition that guards against or prepares for a hypothetical — a test for a bug never seen, a comment against confusion never caused, a guard for a state never reached — waits for a real occurrence that demonstrates it. (This governs the artifacts agents reflexively *proliferate*; it is not a brake on abstraction or configurability, which agents under-use and which often must exist from the start.) The asymmetry is the whole point: speculative justification is unfalsifiable and infinitely available (you can always argue something *might* happen), while an occurrence is certain (you cannot argue something *didn't* happen). Leaving the judgment to a forward-looking "might" is therefore no constraint at all — and because an agent is consistent, the same manufactured justification recurs until every imagined case is "handled" and the work drowns in anticipatory scaffolding nothing ever asked for. React instead to what actually occurred: a bug that bit earns its regression test, a confusion that actually misled earns (maybe) its comment, a state actually reached earns its guard, a second real case earns the abstraction. This is also how an agent becomes trustworthy rather than merely watched: a consistent agent's mistakes will recur, so grounding each safeguard in its first real occurrence lets observed behavior — not pre-imagined behavior — shape the system, and a mistake met once is met for good. The default is to wait for the occurrence; the burden on anyone pre-building for an imagined one is to point at where it already happened. Flag an artifact added in anticipation — a test, comment, guard, abstraction, or knob — justified by a forward-looking "might" or "could" rather than a demonstrated occurrence that already happened.
