A check exists to produce information; reducing its output to a convenient proxy — a grep count, an exit code with the output piped away, an adjacent log line read in place of the check's own report — and acting on the proxy discards the very thing the check was for. The proxy answers a narrower question than the check does, and the gap between them is where failures hide: the count matches while the content changed, the exit is clean while the warning scrolled past unread. Read the check's actual output, from its stated source, before acting on its verdict. Flag a decision taken on a derived scalar or shortcut signal where the underlying output was available and went unread — especially a gate or test whose report was summarized away.
