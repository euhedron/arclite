Verification bears evidence only when the state it runs against was produced by the system being verified — or arrived from the world — not authored by the verifier. A fabricated scenario (a hand-staged worktree posing as an interrupted run, a planted file mimicking a failure, seeded data imagined to resemble real use) tests code against its author's imagination of the conditions, and code and fabrication come from the same mind: misunderstand what the real state looks like and you misbuild the one and mis-stage the other the same way, so the exercise passes while reality diverges. A pass against synthetic state certifies agreement with your own model, not with the system; a failure may indict only the staging. The fabrication also compounds the speculation it rides on — the scenario was prompted by no observed instance, so nothing guarantees it is even realistic, and effort flows into polishing an invented world. Real-state exercise is the evidence-bearing form: run the path on states the system actually produced, and where none exist yet, that too is information — ship, let first real use be the test, and account for what it catches. (Sibling of self-authored text as authority: there, your own prose cannot authorize a claim; here, your own staged state cannot evidence a behavior.) Flag a verification or demonstration run against state the verifier fabricated to resemble a situation no experience has produced — especially one whose pass is then reported as the real path working.
