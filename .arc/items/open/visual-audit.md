A visual audit: findings about the UI itself — layout, alignment, disclosure, legibility — judged from literal screenshots of the running TUI. The pieces exist end to end: the committed tape (`assets/arc-tui.tape`) regenerates every surface as PNGs with one command; the claude backend reads images when granted the `Read` tool; taxonomies and rulesets are per-run configuration. The first step composes them with zero new machinery — a `ui-feedback` ruleset/taxonomy and a run over the shots directory with a Read grant — and the findings' quality decides what, if anything, arc must grow for it (an image-aware context source is the likely candidate). The tape doubles as the documentation pipeline: the README's GIF regenerates from it.
