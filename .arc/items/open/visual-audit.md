A visual audit: findings about the UI itself — layout, alignment, disclosure, legibility — judged from literal screenshots of the running TUI. The pieces exist end to end: the committed tape (`assets/arc-tui.tape`) regenerates every surface as PNGs with one command; the claude backend's image reading when granted the `Read` tool is the enabling capability — to be verified in an arc run before anything is built on it, as the first step below does; taxonomies and rulesets are per-run configuration. The first step composes them with zero new machinery — a `ui-feedback` ruleset/taxonomy and a run over the shots directory with a Read grant, which is also where the image-reading capability gets its checkable provenance — and the findings' quality decides what, if anything, arc must grow for it (an image-aware context source is the likely candidate). The tape doubles as the documentation pipeline: the README's GIF regenerates from it.
