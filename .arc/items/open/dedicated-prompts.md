Extract the verb prompts — today inline in Rust (the per-verb role directives, plus the shared assembly: the grounding guardrail, the structured/ranked notes, the taxonomy block) — into dedicated Markdown assets embedded into the binary the way `.arc/rules` are, so a prompt is edited and reviewed as prose rather than as Rust (a rebuild re-embeds it, exactly as with the rules). This makes concrete the roles-as-Markdown step the verbs-as-configurations question names. Then add a dedicated **prompt-quality** meta-ruleset and a pre-push meta-gate that audits the prompts against it when they change — the exact apparatus `rule-quality` already has over `.arc/rules`, dedicated for the same reason: an inline prompt reads as a *string* to the code audit, and prompt-quality is a different intelligence than code-quality (DRY, no-hardcoding). Seed prompt meta-rule: a prompt names the role and the grounds and stops — it does not prescribe the tools, the reasoning, or the thinking-process the model is meant to own; over-instruction usurps the judgment arc's premise reserves for the model, and is brittle across model versions. Prompts are first-class curated artifacts — their articulation is as significant as a rule's, however short. The validation that earns the ruleset (the curation bar — exercise, don't assume) is running prompt-quality against arc's own role directives — does arc over-instruct its own agents? — not a planted rule that only shows the register parses. The meta-audit targets the **fully-assembled prompt** — what the model actually receives — since over-instruction introduced by shared assembly is invisible in a role directive read alone; the authored role is where a finding is then fixed. The criterion for what becomes editable Markdown versus stays structural glue: a fragment is extracted when it carries role- or grounds-shaping language a reviewer would tune (the grounding guardrail, the structured/ranked notes), and stays code when it is purely mechanical assembly (field interpolation, list joining) that carries no judgment.
