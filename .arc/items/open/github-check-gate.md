Run the audit gate as a GitHub check on this repository. The check itself has landed — `.github/workflows/audit-gate.yml` runs the hook's own audit invocation (`arc run audit . --backend claude --include src --findings --fail-on-findings`, the backend explicit and the key Anthropic's) on every pull request, with arc installed pinned and checksum-verified from Releases and the backend CLI pinned to the boundary-audited version (`npm install -g @anthropic-ai/claude-code@2.1.216`; setup doc: <https://code.claude.com/docs/en/setup>, 2026-08-22); the workflow's steps are deliberately the seed the arc-action composite extracts, so the workflow and the future Action can't fork. What stays open is making the check *unbypassable*: this is an opt-in enforcement layer, never a replacement — the offline/local hook stays first-class (arc runs with no GitHub at all) — and wiring it as a required status check, a branch-ruleset change that is the operator's call once the check proves itself on real PRs, is what adds the unbypassable property: you can't bypass what you chose to enforce. (The workflow runs on same-repo PRs only — a fork's run has no secret access, and a skipped job satisfies a required check; how fork PRs get audited is part of the flip decision, not before it.) Prerequisite in place: the `ANTHROPIC_API_KEY` repository secret (set 2026-08-19; verify: `gh secret list --repo euhedron/arclite`). Remaining beside the flip: ingesting the uploaded run-record artifact into the local ledger in the ledger's own native shape (appended idempotently by run id, so cloud spend enters `arc usage`; grouping CI and local spend under one lens consumes the machine-independent project identity that nothing yet provides — the landed discovery map keys by per-machine path, and the runner's checkout path is a different machine's path for the same project — a gap this item owns as part of the ingest edge: a cross-machine key anchored in the repo itself rather than its path, designed when the ingest lands, extending the map's identity rather than duplicating it); and public output stays verdict-only until public-run-record's projection lands, which the full output shape inherits. (Scope boundary: this item is arclite gating itself; the reusable packaging is github-action's, the installable surface github-app's.)
