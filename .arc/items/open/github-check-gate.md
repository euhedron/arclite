Run the audit gate as a required GitHub check on this repository: a workflow that runs `arc run audit --fail-on-findings` on pull requests, wired as a required status check on main, so the gate binds at the merge boundary rather than only at each contributor's pre-push hook. (Scope boundary: this item is arclite gating itself; the generalized arc-in-Actions offering for any repo belongs to rulespace-registry.) Prerequisite in place: the `ANTHROPIC_API_KEY` repository secret (set 2026-08-19, keychain piped to `gh secret set` so the value never entered an agent context; re-verify with `gh secret list --repo euhedron/arclite`). To keep the ledger whole, the CI run's record is ingested into the local ledger — idempotent by run id, in the projected format public-run-record defines — so cloud spend appears in `arc usage` beside local spend. On a public repo the check's log output is itself public: verdict-only until the public-run-record projection lands; the full output shape inherits it.
