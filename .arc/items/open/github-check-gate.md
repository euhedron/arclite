Run the audit gate as a required GitHub check on this repository: a workflow that runs `arc run audit --fail-on-findings` on pull requests, wired as a required status check on main, so the gate binds at the merge boundary rather than only at each contributor's pre-push hook. (Scope boundary: this item is arclite gating itself; the generalized arc-in-Actions offering for any repo belongs to rulespace-registry.) Needs an `ANTHROPIC_API_KEY` repository secret (set without the value ever entering an agent context) and, to keep the ledger whole, ingestion of the CI run's record into the local ledger — idempotent by run id — so cloud spend appears in `arc usage` beside local spend. On a public repo the check's log output is itself public: it stays minimal (verdict only) until the public-record open question (README) is decided — the full output shape inherits that decision.
