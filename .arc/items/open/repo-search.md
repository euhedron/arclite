Search across one or more repos: one arc command that queries a set of repositories arc already knows — scoped in this first shape to the ledger's lens, deliberately narrower than the landed discovery map (extending the search across the map's discovered-but-unledgered repos is a concrete later edge — the map exists; the choice to start narrower is deliberate) — returning matches with repo-qualified paths — the deterministic complement to the AI verbs for cross-repo questions. First shape: literal/regex content search plus filename matching, gitignore-aware like the scan; symbol-aware search is a later edge. A second target beside file content: arc's own structured objects — items, findings, rules, and (once they exist) facets — searchable and filterable by class and kind, so locating "the open question about X" is a query, never a grep over rendered prose; the sibling context engines (commissure, crux) prove the fuller form with semantic search over all stored objects.
