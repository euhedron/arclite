A direct-API backend: SDK synthesis without an agent CLI, with natively structured output, so it meets the backend membership criterion — schema enforcement, the load-bearing contract everything downstream acts on. The shape: the Anthropic Messages API first — the claude backend's own provider, whose constrained-decoding structured-output guarantee arc already relies on and whose auth is the same `ANTHROPIC_API_KEY`, so no new credential model; one-shot structured synthesis, not an agent loop, so the execution boundary is strictly tighter than the CLI backends (one request, no tools, no filesystem). Its budget contribution is an exact **token** budget, enforced before the request rather than metered after: input is counted authoritatively (the provider's `count_tokens`; arc's 4:1 character estimate is display-only and never the basis), output is bounded by the API's `max_tokens` ceiling, so the request's worst-case token spend (counted input + `max_tokens`) is bounded exactly up front — the by-construction spend bound codex lacks, exposed as a per-request token ceiling the operator can set. It does **not** honor `max_budget_usd`, which is a hard *dollar* cap: a current pricing table could price tokens to dollars, but published rates can change between releases, so the dollar figure can't be the exact contract `max_budget_usd` demands. And arc already handles that case — `reject_unsupported` rejects an explicit `--max-budget-usd` before spend on a backend that can't honor it, and a settings-configured cap is disclosed as not-applied — so on this backend `max_budget_usd` behaves exactly as on codex (explicit flag rejected, settings value disclosed), never silently; the native lever this backend adds is the token budget. The needs this backend serves, any of which is reason to build it: a hard spend cap, which codex has none of; CI where installing a full agent CLI for one headless audit is the heavier dependency; and build-verb's named escalation (arc owning its own agent loop), which would need a first-class API connection of its own. Acceptance: a registry row behind the same `Backend` trait, provider-guaranteed structured output, a native per-request token budget enforced before spend, that boundary reported like every run's.
