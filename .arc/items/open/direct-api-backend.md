A direct-API backend: SDK synthesis without an agent CLI — natively structured output, so it passes the backend membership criterion. Confronted triggers, any of which scheduling for work adopts this item: the codex backend has no native cost cap (every codex run prints `max_budget_usd` as not applied — a direct API loop enforces a budget by construction, metering tokens per request); CI installing a full agent CLI for one headless audit; and build-verb's named escalation (arc owning its own agent loop), which would need a first-class API connection of its own. The shape: the Anthropic Messages API first — the claude backend's own provider, whose constrained-decoding structured-output guarantee arc already relies on and whose auth is the same `ANTHROPIC_API_KEY` path, so no new credential model; one-shot structured synthesis, not an agent loop, so the execution boundary is strictly tighter than the CLI backends (one request, no tools, no filesystem) and the budget is enforced by metering tokens per request against `max_budget_usd`. Acceptance: a registry row behind the same `Backend` trait, provider-guaranteed structured output, the hard budget honored natively, that boundary reported like every run's.
