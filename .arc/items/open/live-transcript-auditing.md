The real-time counterpart to the change gate — the same levers arc already runs (rules, taxonomies, firing records, curation by exercise) pointed at a different change stream: an agent session's reasoning and tool use (transcripts, hook events) instead of a repository's diffs. A cheap opt-in run tails a live session via agent-CLI hook events, or the session transcripts those CLIs already write, checks it against the behavioral ruleset, and notifies or feeds the caught pattern back mid-run; firing rates then curate the behavioral rules exactly as they curate the code rules. Its prerequisite is satisfied: the behavioral ruleset exists (drafted, `.arc/behavioral-rules`), and drafted is sufficient by design — live exercise is how a behavioral rule earns adoption, and this item is the live exercise. Start with the cheapest honest loop (audit a finished transcript on demand) before anything live.
