A real-time counterpart to the change gate, and a core piece of arc's value proposition to make live and visible — not forever deferred. The unification that defines it: the same levers arc already runs — rules, taxonomies, firing records, curation by exercise — pointed at a different change stream: an agent session's reasoning and tool use (transcripts, hook events) instead of a repository's diffs. A cheap opt-in run tails a live session — via agent-CLI hook events, or the session transcripts those CLIs already write — and checks it against the behavioral ruleset, notifying or feeding the caught pattern back mid-run; firing rates then curate the behavioral rules exactly as they curate the code rules. Motivating class of catch, from arc's own build sessions: proxy verification — a gate's exit masked behind a pipe, an adjacent log line read in place of the hook's printed pointer — the kind agent self-memory keeps failing to prevent and this auditing is designed to supersede. Depends on the behavioral ruleset existing; start with the cheapest honest loop (audit a finished transcript on demand) before anything live.
