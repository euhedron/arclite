The real-time counterpart to the change gate — the same levers arc already runs (rules, taxonomies, firing records, curation by exercise) pointed at a different change stream: an agent session's reasoning and tool use instead of a repository's diffs. Two integration modes, distinct in capability and kept distinct here: **transcript auditing** — reading the session files the agent CLIs already write (located through device-awareness's map, never guessed) — is observation: it works on any session, finished or live-tailed, and needs nothing from the agent's own configuration; **hook integration** — the agent CLI invoking arc from inside its loop on conversation/tool-use events — is in-loop: it can judge an action as it happens and feed the verdict back (notify, pause, block) mid-run. Hook support varies by CLI and each claim carries provenance: Claude Code documents its hook events (the References list cites them); codex's equivalent surface is to be verified before anything is built on it. Both modes check against the behavioral ruleset, and firing rates curate the behavioral rules exactly as they curate the code rules. The prerequisite is satisfied: the ruleset exists (drafted, `.arc/behavioral-rules`), and drafted is sufficient by design — live exercise is how a behavioral rule earns adoption, and this item is the live exercise. Start with the cheapest honest loop (audit a finished transcript on demand), then live tailing, then hooks.
