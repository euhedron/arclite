Link the gate's runs into their rounds, and the rounds into their convergence story. A *round* is one push attempt (one hook invocation); a *run* is one gate command within it. The hook exports a round id — one env var, generated once per invocation — and the set of pushed refs, both of which every run in that invocation records (the run record carries repo and commit today but not the refs, so the pushed-ref set is the new field this item adds alongside the id). One hook invocation can carry several pushed refs (git feeds them as multiple stdin lines); the round records them as the set it pushed, and a round belongs to a convergence sequence by *ref-set intersection* — consecutive rounds that share any pushed ref continue the same sequence, since that shared ref is what kept being re-pushed to converge. Those sequences, each ending in the round that passes, are derived in log/usage by adjacency over runs sharing a ref rather than stamped — the recorded ref-set is what makes "same ref" checkable, the round id what groups runs into one round. Needs the gate-invocation stamp (round id + pushed-ref set) and those record fields — the stamp's home today is the hook script, and it works on the current hook and depends on nothing from gate-configuration — correctly ordered ahead of it — and relocates into `arc gate` when gate-configuration later collapses the hook to a shim (a round is one gate invocation, wherever the gate runs from; the stamp survives the relocation unchanged).
