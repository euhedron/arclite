Link the gate's runs into their rounds, and the rounds into their convergence story. Vocabulary pinned to the README's: a *round* is one push attempt (one hook invocation); a *run* is one gate command within it. The hook exports a round id — one env var, generated once per invocation — and the pushed ref, both of which every run in that invocation records (the run record carries repo and commit today but not the ref, so the ref is the new field this item adds alongside the id). Consecutive rounds on the same ref, ending in the one that passes, are the convergence sequence, derived in log/usage by adjacency over runs sharing a ref rather than stamped — the ref is what makes "same ref" checkable, the id what groups runs into one round. Needs the gate-invocation stamp (round id + ref) and those record fields — the stamp's home today is the hook script, and it relocates into `arc gate` when gate-configuration later collapses the hook to a shim (a round is one gate invocation, wherever the gate runs from; the stamp survives the relocation unchanged).
