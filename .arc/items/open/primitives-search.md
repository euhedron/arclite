Search over arc's own primitives: items, findings, rules, and (once they exist) facets and lexicon terms — filterable by **class** (which primitive — item, finding, rule, facet, term) and, within a class, by the discriminators that class actually has (a finding's status/origin, a rule's ruleset, an item's open/resolved state); there is no shared cross-class `kind` field, so the filter surface is per-class, not a single uniform enum invented for the search. Matched by text, from the CLI and the TUI (the `/` palette's type-to-filter idiom pointed at data instead of commands) — so locating "the open question about X" or "the rule about Y" is a query, never a grep over rendered prose. (The generic cross-repo content search this item once carried is dropped: `rg` and the agents' own search tools own that space, and no confronted need ever distinguished an arc variant — it returns on merit if one does.)
