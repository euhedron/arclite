Search over arc's own primitives: items, findings, rules, and (once they exist) facets — filterable by class and kind, matched by text, from the CLI and the TUI (the `/` palette's type-to-filter idiom pointed at data instead of commands) — so locating "the open question about X" or "the rule about Y" is a query, never a grep over rendered prose. The sibling context engines (commissure, crux) prove the fuller form with semantic search over all stored objects. (The generic cross-repo content search this item once carried is dropped: `rg` and the agents' own search tools own that space, and no confronted need ever distinguished an arc variant — it returns on merit if one does.)
