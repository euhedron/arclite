The status view's run lists become navigable — the log view's selection model applied to the two flat tables. Active runs gain a selected cursor: `enter` opens the highlighted run's live detail, watching its streamed progress accumulate; the marker registry streams counters today (turns, tool calls, output chars), not the output text itself, so the live detail starts from what the marker carries, and this item owns deciding where a run's streaming text gets a readable home for the cockpit to tail. Recently completed gains the same cursor: `enter` opens the completed run's detailed view — what `arc log <id>` renders — without leaving the cockpit. Sibling to tui-usage-navigation and tui-feedback-navigation.
