The status view's run lists become navigable — the log view's selection model applied to the two flat tables. Active runs gain a selected cursor: `enter` opens the highlighted run's live detail, watching its streamed progress accumulate; the marker registry streams counters today (turns, tool calls, output chars), not the output text itself, so this item gives a run's streaming text a readable home: the run appends its output to a per-run log file beside its live marker in the run area, and the live detail tails that file — the same append-as-you-go stream the counters already come from, extended to carry the text. On completion the live log is superseded by the stored result `arc log <id>` renders (the live file is working state, the stored result the durable record), so the detail view switches from tailing to the stored render when the run ends. Recently completed gains the same cursor: `enter` opens the completed run's detailed view — what `arc log <id>` renders — without leaving the cockpit. Sibling to tui-usage-navigation and tui-feedback-navigation.
