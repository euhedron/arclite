A lexicon — essentially a glossary: the project's core concepts and terms with their preferred forms, definitions, and descriptions, so judgment consults the project's vocabulary as declared grounds. Drift becomes a *finding* not automatically but through the consuming verb's taxonomy: a lexicon-conformance kind in the judgment verbs' vocabularies (a term used off its preferred form, a defined concept contradicted) is what turns divergence into a reportable item — the lexicon supplies the grounds, the taxonomy makes a departure from them a finding, the same split rules and the rule taxonomy already have. Like facets but one level up: high-level and implementation-independent — where facets describe the project, the lexicon establishes the meaning of the words the describing (and all judgment over the project) is conducted in — background context ensuring reasoning stands on a common language and that the vocabulary used in content and code stays restricted and consistent. The shape, following the rules and facets substrate: flat Markdown entries in one folder — shipped default `.arc/lexicon/`, the folder settings-overridable like every configured path — one term per file, filename stem the canonical form, body the definition and description. It is not a ruleset — names and meanings are grounds a judgment consults, not general principles — and it needs no separate validator: it enters synthesis as a declared, reported context source, selected the way other context is: a `lexicon` settings boolean defaulting **on** once a lexicon folder exists (absent the folder there is nothing to add, so it is inert, never an error), with `--lexicon`/`--no-lexicon` overriding per run and selecting whether that resolved folder's terms enter the run. The verbs that consult it when enabled are the judgment verbs whose grounds it sharpens (audit, align, critique, suggest, evolve, and orient once it lands), not the purely descriptive ones (summarize), so those judgment runs automatically receive it where a folder exists and the setting is on; drift is caught by that judgment consulting it, the same way rules and taxonomies ground a run. It is its own class under the classes-by-role doctrine, with the sibling context engines' term/entity substrate (commissure, crux) the working exemplar.
