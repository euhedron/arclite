A lexicon: canonical project terms and their casing, enforced so naming drift in product and repo names is auto-caught rather than hand-policed. First shape: a JSON pack of `{term, casing}`, checked deterministically where exact matching suffices, AI judgment only for context-dependent drift; seeded with Euhedron's own names (Euhedron, arclite, Arc, crux, commissure, rulespace). A facts pack, not a ruleset — the general lever is the lexicon check itself; each pack carries one org's canonical spellings, deliberately outside the rules' general-principle bar. Entry points, honoring the deterministic-vs-AI split: the exact-match sweep is a deterministic top-level command (exit-coded, gate-composable like the rest); the context-dependent half is no new verb — the pack composes into an ordinary audit run as a source.
