Verify releases on machines that aren't ours: a post-release workflow that downloads each published binary onto fresh per-OS runners and exercises `doctor`, `init`, and `--version` — and exercises `arc update --apply` from the previous release — so a broken asset is caught by ephemeral clean machines instead of a user. The same workflow should `brew install` from the tap and run the install scripts, so every distribution channel is exercised, not just the raw assets. Remaining distribution residue beyond the landed channels (tap, install scripts, SHA256SUMS): crates.io (flipping the manifest's deliberate `publish = false` gate — a permanent name claim, operator's call), cargo-binstall, Scoop/WinGet. Signed-release verification (out-of-band key or build attestations) stays the deeper edge beyond all of it.
