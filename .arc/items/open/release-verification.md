Verify releases on machines that aren't ours: a post-release workflow that downloads each published binary onto fresh per-OS runners and exercises `doctor`, `init`, and `--version` — and exercises `arc update --apply` from the previous release — so a broken asset is caught by ephemeral clean machines instead of a user. An install one-liner and package-manager presence (crates.io, cargo-binstall, Homebrew, Scoop) ride this item — distribution is release work. Signed-release verification stays the deeper edge beyond it.
