The discovery indexes already exist and are read deterministically: the agent CLIs' own session stores — Claude Code's `~/.claude/projects/` holds one directory per project with the repo path encoded in the name (`-Users-…-code-arclite`), repo-addressable without opening a file; codex's `~/.codex/sessions/` holds `rollout-<timestamp>-<uuid>.jsonl` files whose repo lives *inside* the session record, with layout varying by version (loose files and year-dated subdirectories both observed) — both verified on this machine 2026-08-23 (`ls ~/.claude/projects`; `ls ~/.codex/sessions`), to be re-verified wherever discovery runs since neither layout is contractual — and arc's own ledger's recorded repo paths — an operator disables or mutes discovered entries (the `muted_repos` posture) rather than having to name what the machine already records; adding an undiscovered root stays an optional extra, never a prerequisite. Per repo: session counts and latest-activity recency, live sessions distinguished from recently-finished ones. Read-only enumeration — no transcript content is read at this layer. Surfaced where the cross-repo cockpit already lives (the TUI home/status seat, and a CLI read beside it), disclosed like every lens.
