Live device awareness — the substrate real-time auditing stands on: arc knows the repositories on this machine and the agent activity around them, by discovery, not declaration. The discovery indexes already exist and are read deterministically: the agent CLIs' own session stores (Claude Code's per-project directories encode repo paths in their names; codex keeps a session store), and arc's own ledger's recorded repo paths — an operator disables or mutes discovered entries (the `muted_repos` posture) rather than having to name what the machine already records; adding an undiscovered root stays an optional extra, never a prerequisite. Per repo: session counts and latest-activity recency, live sessions distinguished from recently-finished ones. Read-only enumeration — no transcript content is read at this layer. Surfaced where the cross-repo cockpit already lives (the TUI home/status seat, and a CLI read beside it), disclosed like every lens. Consumers: live-transcript-auditing locates transcripts through this map rather than guessing paths, and repo-drift-metrics extends the same per-repo rows with its git/ledger figures. The session stores are external surfaces: their locations and formats carry provenance (the CLI's docs plus date, or a verifying command) per the claims doctrine.
