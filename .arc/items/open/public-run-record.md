Project a repo's run record into the repo — the shape the public-record design discussion settled (the README's open question keeps only the residue). `.arc/record/` as a derived render off the authoritative private ledger: written by an explicit `arc sync`, never in the run hot path; idempotent by run id; an allowlist of fields only — id, timestamp, arc version, verb, backend and model, rules and taxonomy as (id, hash) pairs, gate verdict and blocked/passed, the structured findings and note, commit anchor, and a `format` version — never prompts, absolute paths, or other-repo traces, with cost only under an opt-in setting. Off by default everywhere; arclite opts in as the dogfood and the operator judges the actual emitted record.
