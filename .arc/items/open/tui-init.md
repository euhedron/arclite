A TUI init flow: scaffold a repo — `.arc`, the hook, the default ruleset selection — from inside the cockpit, the way the agent CLIs offer setup from inside a session, instead of requiring a trip back to the shell. Entry: the cockpit home view surfaces discovered repos without `.arc/` as init candidates (global-cockpit's onboarding affordance, distinct from the arc-enabled cockpit rows); the scaffold is offered as an action on such a candidate; it runs through the same `arc init` path the CLI uses (hook on/off, ruleset selection — never a parallel implementation), behind a confirm step modeled on the run launch's preview (not yet every TUI write surface's pattern — config edits and feedback captures today write directly on Enter): the confirm lists exactly the files it will create and the ruleset it will select before anything is written. An existing `.arc` is reported as already-initialized and the flow offers nothing destructive — no overwrite, re-scaffold, or merge — matching `arc init`'s own idempotent, non-destructive contract.
