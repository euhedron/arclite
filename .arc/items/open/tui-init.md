A TUI init flow: scaffold a repo — `.arc`, the hook, the default ruleset selection — from inside the cockpit, the way the agent CLIs offer setup from inside a session, instead of requiring a trip back to the shell. Entry: from the cockpit's repo/home view on a repo with no `.arc`, the scaffold is offered as an action on that row; it runs through the same `arc init` path the CLI uses (hook on/off, ruleset selection — never a parallel implementation), exposed as the preview-gated launch every spend/write surface in the TUI already uses: the confirm step lists exactly the files it will create and the ruleset it will select before anything is written. An existing `.arc` is reported as already-initialized and the flow offers nothing destructive — no overwrite, re-scaffold, or merge — matching `arc init`'s own idempotent, non-destructive contract.
