When a channel or platform natively enforces a property — schema-conformant structured output and strict tool calls via constrained decoding, a database constraint, a checksummed transport, a type system — do not re-implement that enforcement locally: redundant re-validation is speculative defense that misstates where the guarantee lives and rots independently of it. The real work is establishing, with checkable provenance, that the guarantee exists and is active — many are opt-in — then acting on the channel's word, confining local handling to failures the guarantee does not cover: absence, truncation, transport corruption. Flag local re-validation of a property the channel already guarantees, and equally code built on an assumed guarantee that nothing cited establishes.
